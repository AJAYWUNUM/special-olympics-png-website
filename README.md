# Special Olympics Papua New Guinea website

A lightweight, responsive static website for Special Olympics Papua New Guinea (SOPNG).

## Preview

Open the homepage in a browser, or serve this folder with any static web server. There is no build step or third-party runtime dependency.

## Pages

- Home
- About and history
- Programs directory with five dedicated program detail pages
- Events and community highlights
- Donation, volunteer and partnership enquiries
- Contact details

Older program URLs redirect to their matching detail pages; other archived page URLs point to relevant sections of the new site.

## Content and imagery

Page content and photographs were adapted from the supplied SOPNG website archive. The included images are resized WebP versions for faster loading. Program dates, names and office details reflect that archive; no upcoming event schedule or payment service was supplied.

The archived email address is retained as written in the source: specialoplymicspapuaniuginini@gmail.com. Confirm it with SOPNG before launch if it has changed.

## Files

- site.css — layout, colors, responsive styles and reduced-motion support
- site.js — mobile navigation and current-year footer
- assets — SOPNG logo, favicon and optimized program photographs
